  • Voxel world: grass, dirt, stone, sand, water, trees, caves
  • Break / place blocks, swimming, double-tap Space to fly
  • Saved worlds (browser storage)
  • P2P multiplayer (PeerJS): host with room code, private or public, join by code or list
  • Host-authoritative block edits, shared seed, player avatars
